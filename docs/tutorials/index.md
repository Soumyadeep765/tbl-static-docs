# Tutorials

Work through these in order if you're new to TBL. Each one builds on the last — by the end you'll have a bot that handles commands, buttons, aliases, typed input, and unknown messages.

You don't need to write much code at first. TeleBotHost lets you get a working bot using only the command editor. Logic comes later, when you need it.

## The series

1. **[Command Structure](../getting-started-with-tbl/command-structure.md)** — how TBL thinks about triggers, answers, logic, and the special commands (`@`, `!`, `*`, and the rest). Read this before touching anything else.
2. **[Your First Bot](../getting-started-with-tbl/first-hello-bot.md)** — a `/start` command that actually replies. Takes about five minutes.
3. **[Adding a Keyboard](../getting-started-with-tbl/adding-keyboard.md)** — replace typing with tap-able buttons.
4. **[Using Aliases](../getting-started-with-tbl/adding-aliases.md)** — one command, several ways to trigger it.
5. **[Handling User Input](../getting-started-with-tbl/handle-need-reply.md)** — wait for the user's next message and use it.
6. **[Wildcard Command](../getting-started-with-tbl/using-wildcard.md)** — catch everything that doesn't match anything else.

## Before you start

Make sure you've [added a bot on TeleBotHost](../getting-started.md) and launched it at least once. The tutorials assume you can open the Commands panel and see your bot respond on Telegram.
