# Tutorials

Building a Telegram bot can feel overwhelming, but you don't have to start by writing complex database connections and API loops. In fact, on TeleBotHost, you can build full-blown interactive menus using just the dashboard fields—no code required! 

When you need your bot to make smart decisions, you can sprinkle in **JavaScript Logic** to handle the heavy lifting.

---

## The Hands-On Series

Work through these lessons in order. Each one is a quick, five-minute step that builds directly on the previous one:

1. **[Your First Bot](../getting-started-with-tbl/first-hello-bot.md)** — Create a simple `/start` command that says hello.
2. **[Adding a Keyboard](../getting-started-with-tbl/adding-keyboard.md)** — Put reply buttons on the screen so users can tap instead of typing.
3. **[Using Aliases](../getting-started-with-tbl/adding-aliases.md)** — Make one command respond to multiple different button labels or typos.
4. **[Handling User Input](../getting-started-with-tbl/handle-need-reply.md)** — Pause the flow, ask the user a question, and wait for their reply.
5. **[Handling Callbacks](../getting-started-with-tbl/handling-callbacks.md)** — Add clean inline buttons directly inside message bubbles.
6. **[Wildcard Command](../getting-started-with-tbl/using-wildcard.md)** — Set up a safety net command to catch any random input your bot doesn't understand.
