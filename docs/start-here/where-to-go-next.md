# Where To Go Next

You do not need to read the whole documentation in order. Pick the next topic based on the thing your bot should do next.

For buttons under the chat input, read [Adding a Keyboard](../getting-started-with-tbl/adding-keyboard.md).

For one command that responds to several words or button labels, read [Using Aliases](../getting-started-with-tbl/adding-aliases.md).

For asking the user a question and waiting for their answer, read [Handling User Input](../getting-started-with-tbl/handle-need-reply.md).

For inline buttons inside a message, read [Handling Callbacks](../getting-started-with-tbl/handling-callbacks.md).

For saving data, start with [Database Storage](../db-instance/index.md).

For calling another website or API, start with [HTTP](../http-instance/index.md).

For public pages, mini apps, or custom endpoints, start with [Webapps](../webapp-instance/index.md).

Use the reference sections when you already know the object name and need details.
